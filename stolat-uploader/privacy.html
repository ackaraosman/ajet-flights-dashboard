StoLat Uploader – Privacy Policy

Last updated: 2 November 2026

StoLat Uploader is a private tool operated by the owner of the YouTube channel StoLatStoLat. It is used only by that owner, on their own computer, to manage their own channel.

What data the tool accesses

With the owner's consent through Google OAuth, the tool uses the YouTube Data API to upload videos to the owner's channel, edit their titles, descriptions, tags, thumbnails and settings, add them to the channel's playlists, and post and read comments on the channel's own videos. It reads basic channel information (channel name and ID) to confirm it is connected to the right channel.

How data is stored

The OAuth access token is stored only on the owner's computer. No data is sent to any server other than Google's APIs. The tool has no database, no analytics and no tracking.

Sharing

No data obtained through Google APIs is sold, shared with or transferred to third parties. StoLat Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, and to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections, which also invalidates the stored token.
